# Earnings review

Review `day-trader-skill` `trader-analyst/facts.py --json` output without changing
its files. Compatibility was executed against commit
`3d0f4ef6986f4984b7c6bd46f7ff4f87744c3abd`. No upstream code is bundled.

## Try three offline cases

```sh
python -m ahasignals_pit.workflow_cli earnings-demo --out demo-results
```

Expected: `correct: SUPPORTED`, `wrong: CORRECTION_REQUIRED`,
`insufficient: UNKNOWN`. Each result also says `REVIEWED_ANNOTATIONS_ONLY`.
These are deterministic program checks on selected reviewed facts, not model
accuracy tests or freshly authenticated source documents. Wrong/insufficient
inputs are constructed mutations; they are not reported bugs in upstream output.

The correct export was generated by the actual pinned upstream functions using
three reviewed CoreWeave 2025 Q2 facts reconstructed in Company Facts format.
Revenue is USD 1,212,788,000, operating income USD 19,209,000, and net loss
USD 290,509,000. Source: https://www.sec.gov/Archives/edgar/data/1769628/000176962825000041/crwv-20250630.htm
Consolidated statements of operations, page 7, three months ended June 30, 2025.
The deliberately wrong case substitutes the January–June operating loss into the
quarter and changes its margin. The insufficient case adds an unsupported cash
flow amount. The output preserves valid numbers while exposing missing evidence.

## Re-extract the original

```sh
python -m ahasignals_pit.workflow_cli fetch-claim-source --out private-source
python -m ahasignals_pit.workflow_cli earnings-demo --source private-source/source.html --out original-results
```

The explicit existing collector retrieves one public SEC URL. Denial remains
unknown; no proxy or retry. Original HTML stays local and is not redistributed.
Successful hash, CIK, context, period, unit, sign, scale and literal checks change
the evidence level to `REVIEWED_ORIGINAL_REEXTRACTED`. Changed bytes return UNKNOWN,
even if annotation-only checks would pass. A hash is not independent authentication.

## Your own output

Run the upstream tool in its own checkout with your authorized SEC User-Agent:

```sh
python trader-analyst/facts.py CRWV --json > earnings.json
```

Then use this package:

```sh
python -m ahasignals_pit.workflow_cli review-export --input earnings.json --cutoff 2026-11-03T00:00:00Z --analysis analysis.txt --out my-review
```

Use your actual research cutoff. `analysis.txt` is an optional UTF-8 file. It is
preserved verbatim as unreviewed text; the engine does not parse arbitrary prose.
Add `--source private-source/source.html` to re-extract this reviewed filing.
The full export may contain newer quarters, more metrics and TTM values: these
remain UNKNOWN unless covered. Do not filter away warnings to call a whole report
verified. `metrics.json` is rejected because it discards the required row context.

Coverage is deliberately explicit: CoreWeave's consolidated 2025 Q2 revenue,
operating income, net income, operating margin and net margin. Other issuers,
periods, EPS, growth, TTM, segment data and investment inferences stay UNKNOWN.
The adapter accepts a general export shape; its reviewed evidence coverage is not
general. New evidence requires a separately reviewed, versioned release.

`disclosure-reconstruction` uses the reviewed acceptance clock.
`observed-pipeline` also requires the retained capture clock. Date-only row `filed`
values never stand in for per-fact provenance. Results expose source locations,
context IDs, units and inputs for every checked number. Existing Microsoft packets
and historical cutoff results are retained; older packets use their pinned package.

## MCP

Run `python -m ahasignals_pit.workflow_mcp` as a local stdio server. Discover
`review_earnings_export`. Supply `payload` (the native JSON array) and `cutoff`,
optionally `analysis`, `mode` and UTF-8 `sourceText`. The tool cannot read a local
path or fetch a URL. CLI, Skill and MCP call the same Python function.

Use `revisedAnalysis` as source-supported numerical replacement text, not as an
approval of the user's thesis. Always show `evidenceLevel`, individual UNKNOWN
checks and `analysisStatus` beside the summary.
