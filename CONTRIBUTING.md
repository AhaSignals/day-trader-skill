# Contributing

Reproduce with a minimal input and expected financial context. Remove personal
paths, tokens and private data. Include issuer, period, units, source URL,
research cutoff and software version. Do not upload original filings here.

Run offline tests and the release audit before a change. Do not overwrite earlier
release assets or reviewed evidence. New evidence needs source review and explicit
clock/basis checks, not just a model extraction. Generic upstream fixes should be
small, independently tested changes; maintain attribution and an upstream commit
pin. Do not advertise model accuracy from software tests or profitability from
simulations. No paid runners, new collection schedules or automatic provider calls.
